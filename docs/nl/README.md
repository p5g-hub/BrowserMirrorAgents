# BrowserMirrorAgents

**Verbind OpenCode en Codex met browser-gebaseerde AI-agenten.**

BrowserMirrorAgents is een self-hosted integratielaag die AI-codingtools verbindt met browser-gebaseerde AI-diensten.

Gebruik je favoriete AI-codingomgeving met Bitrix24, Qwen en DeepSeek via bestaande browsersessies — zonder aparte API-sleutels voor elke provider te hoeven kopen.

## ✨ Waarom BrowserMirrorAgents?

- **Geen aparte API-sleutels** — gebruik browsersessies in plaats van individuele API-toegang te kopen.
- **Meerdere AI-providers** — maak verbinding met verschillende browser-gebaseerde AI-diensten.
- **OpenCode-integratie** — gebruik browser-gebaseerde AI-agenten in je OpenCode-workflow.
- **Codex-integratie** — verbind Codex met ondersteunde browser-AI-diensten.
- **Self-hosted** — voer de applicatie uit op je eigen server.
- **Docker-implementatie** — eenvoudige installatie met Docker Compose.
- **Eenmalige betaling** — geen terugkerend abonnement.

## 🔌 Hoe Het Werkt

BrowserMirrorAgents fungeert als een integratielaag tussen AI-codingtools en browser-gebaseerde AI-diensten.

1. Implementeer BrowserMirrorAgents op je server.
2. Verbind je browser-gebaseerde AI-sessies.
3. Configureer OpenCode of Codex.
4. Begin te werken met ondersteunde AI-providers.

Je daadwerkelijke toegang, gebruikslimieten en beschikbaarheid hangen af van de betreffende AI-provider en je browsersessie.

## 🐳 Installatie

Implementeer BrowserMirrorAgents met Docker.

Vervang `YOUR_LICENSE_KEY` door je persoonlijke licentiesleutel die je na aankoop hebt ontvangen.

`docker run -d --name browsermirroragents --restart unless-stopped -p 8000:8000 -e LICENSE_KEY=YOUR_LICENSE_KEY soft.p5g.ru/browsermirroragents:latest`

Zodra de container draait, open:

**[http://localhost:8000](http://localhost:8000)**

Dat is alles! BrowserMirrorAgents is klaar voor gebruik.

## 🤖 AI-aangedreven Interface Monitoring

**Maak je geen zorgen over interface-wijzigingen. Wij monitoren ze voor jou.**

AI-aangedreven monitoring loopt aan onze kant en houdt wijzigingen bij in ondersteunde AI-diensten en hun browserinterfaces.

Wanneer interface-elementen of selectors veranderen, detecteert ons systeem de updates en publiceert het vernieuwde selectors en compatibiliteitsaanpassingen bijna onmiddellijk.

- **Continue monitoring** — ondersteunde interfaces worden regelmatig gemonitord.
- **AI-aangedreven detectie** — wijzigingen worden automatisch geïdentificeerd.
- **Snelle updates** — vernieuwde selectors en interface-aanpassingen worden snel gepubliceerd.
- **Minder onderhoud** — geen behoefte om interface-wijzigingen handmatig bij te houden of selectors constant zelf bij te werken.

## ❓ FAQ

### Heb ik aparte API-sleutels nodig?

Nee. BrowserMirrorAgents is ontworpen om te werken via bestaande browsersessies, dus je hoeft geen aparte API-sleutels te kopen voor elke ondersteunde provider.

### Welke AI-codingtools worden ondersteund?

OpenCode en Codex.

### Welke AI-providers worden ondersteund?

Bitrix24, Qwen, DeepSeek, Google AI.

### Kan ik het op mijn eigen server hosten?

Ja. BrowserMirrorAgents wordt gedistribueerd als een Docker-image en kan worden geïmplementeerd met Docker Compose.

### Zijn er maandelijkse kosten?

Nee. BrowserMirrorAgents is beschikbaar met een eenmalige licentieaankoop.

### Zijn AI-diensten onbeperkt?

Gebruik hangt af van de beschikbaarheid, beleidsregels en limieten van elke AI-provider en je browsersessies.

Je kunt ook meerdere browseraccounts verbinden en tussen sessies schakelen, onder voorbehoud van de servicevoorwaarden van de respectieve providers.
