**Koble OpenCode og Codex til nettleserbaserte AI-agenter.**

## ✨ Hvorfor BrowserMirrorAgents?

- **Ingen separate API-nøkler** — bruk nettleserøkter i stedet for å kjøpe individuell API-tilgang.
- **Flere AI-leverandører** — koble til forskjellige nettleserbaserte AI-tjenester.
- **OpenCode-integrasjon** — bruk nettleserbaserte AI-agenter i din OpenCode-arbeidsflyt.
- **Codex-integrasjon** – koble Codex til støttede nettleser-AI-tjenester.
- **Selvhostet** — kjør applikasjonen på din egen server.
- **Docker-distribusjon** — enkel installasjon med Docker Compose.
- **Engangsbetaling** — ingen tilbakevendende abonnement.

## 🔌 Hvordan Det Fungerer

BrowserMirrorAgents fungerer som et integrasjonslag mellom AI-koderverktøy og nettleserbaserte AI-tjenester.

1. Distribuer BrowserMirrorAgents på serveren din.
2. Koble til dine nettleserbaserte AI-økter.
3. Konfigurer OpenCode eller Codex.
4. Begynn å arbeide med støttede AI-leverandører.

Din faktiske tilgang, bruksgrenser og tilgjengelighet avhenger av den aktuelle AI-leverandøren og din nettleserøkt.

## 🐳 Installasjon

Distribuer BrowserMirrorAgents ved hjelp av Docker.

Erstatt `YOUR_LICENSE_KEY` med din personlige lisensnøkkel mottatt etter kjøp.

`docker run -d --name browsermirroragents --restart unless-stopped -p 8000:8000 -e LICENSE_KEY=YOUR_LICENSE_KEY soft.p5g.ru/browsermirroragents:latest`

Når containeren kjører, åpne:

**[http://localhost:8000](http://localhost:8000)**

Det var det! BrowserMirrorAgents er klar til bruk.

## 🤖 AI-drevet Grensesnittovervåking

**Ikke bekymre deg for grensesnittendringer. Vi overvåker dem for deg.**

AI-drevet overvåking kjører på vår side og sporer endringer i støttede AI-tjenester og deres nettlesergrensesnitt.

Når grensesnittelementer eller selektorer endres, oppdager systemet vårt oppdateringene og publiserer oppdaterte selektorer og kompatibilitetsjusteringer nesten umiddelbart.

- **Kontinuerlig overvåking** — støttede grensesnitt overvåkes regelmessig.
- **AI-drevet deteksjon** — endringer identifiseres automatisk.
- **Raske oppdateringer** — oppdaterte selektorer og grensesnittjusteringer publiseres raskt.
- **Mindre vedlikehold** — ingen behov for å manuelt spore grensesnittendringer eller konstant oppdatere selektorer selv.

**Vi overvåker grensesnittene. Du fokuserer på arbeidet ditt.**

## ❓ FAQ

### Trenger jeg separate API-nøkler?

Nei. BrowserMirrorAgents er designet for å fungere gjennom eksisterende nettleserøkter, så du trenger ikke å kjøpe separate API-nøkler for hver støttet leverandør.

### Hvilke AI-koderverktøy støttes?

OpenCode og Codex.

### Hvilke AI-leverandører støttes?

Bitrix24, Qwen, DeepSeek, Google AI.

### Kan jeg hoste det på min egen server?

Ja. BrowserMirrorAgents distribueres som et Docker-bilde og kan distribueres ved hjelp av Docker Compose.

### Er det månedlige avgifter?

Nei. BrowserMirrorAgents er tilgjengelig med engangslisenskjp.

### Er AI-tjenestene ubegrensede?

Bruken avhenger av tilgjengeligheten, retningslinjene og grensene for hver AI-leverandør og dine nettleserøkter.

Du kan også koble til flere nettleserkontoer og bytte mellom økter, underlagt de respektive leverandørenes tjenestevilkår.
