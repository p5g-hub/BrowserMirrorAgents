# BrowserMirrorAgents

**Connetti OpenCode e Codex agli agenti AI basati sul browser.**

BrowserMirrorAgents è un livello di integrazione self-hosted che connette gli strumenti di codifica AI ai servizi AI basati sul browser.

Usa il tuo ambiente di codifica AI preferito con Bitrix24, Qwen e DeepSeek attraverso sessioni del browser esistenti — senza acquistare chiavi API separate per ogni provider.

## ✨ Perché BrowserMirrorAgents?

- **Nessuna chiave API separata** — usa le sessioni del browser invece di acquistare l'accesso API individuale.
- **Molti provider AI** — connettiti a diversi servizi AI basati sul browser.
- **Integrazione OpenCode** — usa agenti AI basati sul browser nel tuo flusso di lavoro OpenCode.
- **Integrazione Codex** — connetti Codex ai servizi AI del browser supportati.
- **Self-hosted** — esegui l'applicazione sul tuo server.
- **Distribuzione Docker** — installazione semplice usando Docker Compose.
- **Pagamento unico** — nessun abbonamento ricorrente.

## 🔌 Come Funziona

BrowserMirrorAgents funge da livello di integrazione tra gli strumenti di codifica AI e i servizi AI basati sul browser.

1. Distribuisci BrowserMirrorAgents sul tuo server.
2. Connetti le tue sessioni AI basate sul browser.
3. Configura OpenCode o Codex.
4. Inizia a lavorare con i provider AI supportati.

Il tuo accesso effettivo, i limiti di utilizzo e la disponibilità dipendono dal provider AI corrispondente e dalla tua sessione del browser.

## 🐳 Installazione

Distribuisci BrowserMirrorAgents usando Docker.

Sostituisci `YOUR_LICENSE_KEY` con la tua chiave di licenza personale ricevuta dopo l'acquisto.

`docker run -d --name browsermirroragents --restart unless-stopped -p 8000:8000 -e LICENSE_KEY=YOUR_LICENSE_KEY soft.p5g.ru/browsermirroragents:latest`

Una volta che il container è in esecuzione, apri:

**[http://localhost:8000](http://localhost:8000)**

Fatto! BrowserMirrorAgents è pronto per l'uso.

- **Monitoraggio continuo** — le interfacce supportate vengono monitorate regolarmente.
- **Rilevamento basato su AI** — i cambiamenti vengono identificati automaticamente.

## ❓ FAQ

### Ho bisogno di chiavi API separate?

No. BrowserMirrorAgents è progettato per funzionare attraverso sessioni del browser esistenti, quindi non hai bisogno di acquistare chiavi API separate per ogni provider supportato.

### Quali strumenti di codifica AI sono supportati?

OpenCode e Codex.

### Quali provider AI sono supportati?

Bitrix24, Qwen, DeepSeek, Google AI.

### Posso ospitarlo sul mio server?

Sì. BrowserMirrorAgents è distribuito come immagine Docker e può essere distribuito usando Docker Compose.

### Ci sono canoni mensili?

No. BrowserMirrorAgents è disponibile con un acquisto di licenza una tantum.

### I servizi AI sono illimitati?

L'utilizzo dipende dalla disponibilità, dalle politiche e dai limiti di ogni provider AI e dalle tue sessioni del browser.

Puoi anche connettere più account del browser e passare tra le sessioni, soggetto ai termini di servizio dei rispettivi provider.
