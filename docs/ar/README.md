# BrowserMirrorAgents

**ربط OpenCode و Codex بوكلاء الذكاء الاصطناعي المستندة إلى المتصفح.**

BrowserMirrorAgents هو طبقة تكامل مستضافة ذاتياً تربط أدوات الترميز بالذكاء الاصطناعي بخدمات الذكاء الاصطناعي المستندة إلى المتصفح.

استخدم بيئة الترميز المفضلة لديك مع Bitrix24 و Qwen و DeepSeek من خلال جلسات المتصفح الموجودة — دون الحاجة إلى شراء مفاتيح API منفصلة لكل مزود.

يعتمد الوصول الفعلي وحدود الاستخدام والتوفر على مزود الذكاء الاصطناعي المقابل وجلسة المتصفح الخاصة بك.

## 🐳 التثبيت

انشر BrowserMirrorAgents باستخدام Docker.

استبدل `YOUR_LICENSE_KEY` بمفتاح الترخيص الشخصي الذي تلقيته بعد الشراء.

`docker run -d --name browsermirroragents --restart unless-stopped -p 8000:8000 -e LICENSE_KEY=YOUR_LICENSE_KEY soft.p5g.ru/browsermirroragents:latest`

بمجرد تشغيل الحاوية، افتح:

**[http://localhost:8000](http://localhost:8000)**

هذا كل شيء! BrowserMirrorAgents جاهز للاستخدام.

OpenCode و Codex.

### ما هي مزودي الذكاء الاصطناعي المدعومين؟

Bitrix24، Qwen، DeepSeek، Google AI.

نعم. يتم توزيع BrowserMirrorAgents كصورة Docker ويمكن نشره باستخدام Docker Compose.

لا. يتوفر BrowserMirrorAgents بشراء ترخيص لمرة واحدة.
