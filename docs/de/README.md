# BrowserMirrorAgents

**Verbinde OpenCode und Codex mit browserbasierten KI-Agenten.**

BrowserMirrorAgents ist eine selbstgehostete Integrationsschicht, die KI-Coding-Tools mit browserbasierten KI-Diensten verbindet.

Nutze deine bevorzugte KI-Coding-Umgebung mit Bitrix24, Qwen und DeepSeek über bestehende Browsersitzungen — ohne separate API-Schlüssel für jeden Anbieter kaufen zu müssen.

## ✨ Warum BrowserMirrorAgents?

- **Keine separaten API-Schlüssel** — nutze Browsersitzungen statt individuellen API-Zugang zu kaufen.
- **Mehrere KI-Anbieter** — verbinde dich mit verschiedenen browserbasierten KI-Diensten.
- **OpenCode-Integration** — nutze browserbasierte KI-Agenten in deinem OpenCode-Workflow.
- **Codex-Integration** — verbinde Codex mit unterstützten Browser-KI-Diensten.
- **Selbstgehostet** — führe die Anwendung auf deinem eigenen Server aus.
- **Docker-Bereitstellung** — einfache Installation mit Docker Compose.
- **Einmalige Zahlung** — kein wiederkehrendes Abonnement.

## 🔌 So funktioniert es

BrowserMirrorAgents fungiert als Integrationsschicht zwischen KI-Coding-Tools und browserbasierten KI-Diensten.

1. Stelle BrowserMirrorAgents auf deinem Server bereit.
2. Verbinde deine browserbasierten KI-Sitzungen.
3. Konfiguriere OpenCode oder Codex.
4. Beginne mit der Arbeit mit unterstützten KI-Anbietern.

Dein tatsächlicher Zugriff, Nutzungslimits und Verfügbarkeit hängen vom entsprechenden KI-Anbieter und deiner Browsersitzung ab.

## 🐳 Installation

Stelle BrowserMirrorAgents mit Docker bereit.

Ersetze `YOUR_LICENSE_KEY` durch deinen persönlichen Lizenzschlüssel, den du nach dem Kauf erhalten hast.

`docker run -d --name browsermirroragents --restart unless-stopped -p 8000:8000 -e LICENSE_KEY=YOUR_LICENSE_KEY soft.p5g.ru/browsermirroragents:latest`

Sobald der Container läuft, öffne:

**[http://localhost:8000](http://localhost:8000)**

Das war's! BrowserMirrorAgents ist einsatzbereit.

## ❓ FAQ

### Brauche ich separate API-Schlüssel?

Nein. BrowserMirrorAgents ist dafür entwickelt, über bestehende Browsersitzungen zu funktionieren, sodass du keine separaten API-Schlüssel für jeden unterstützten Anbieter kaufen musst.

### Welche KI-Coding-Tools werden unterstützt?

OpenCode und Codex.

### Welche KI-Anbieter werden unterstützt?

Bitrix24, Qwen, DeepSeek, Google AI.

### Kann ich es auf meinem eigenen Server hosten?

Ja. BrowserMirrorAgents wird als Docker-Image verteilt und kann mit Docker Compose bereitgestellt werden.

### Gibt es monatliche Gebühren?

Nein. BrowserMirrorAgents ist mit einem einmaligen Lizenzkauf verfügbar.

### Sind KI-Dienste unbegrenzt?

Die Nutzung hängt von der Verfügbarkeit, Richtlinien und Limits jedes KI-Anbieters und deinen Browsersitzungen ab.

Du kannst auch mehrere Browser-Konten verbinden und zwischen Sitzungen wechseln, vorbehaltlich der jeweiligen Nutzungsbedingungen der Anbieter.
